## Continued study: Urban Systems Lab

ต่อยอดจาก **Autonomous E-Bus Model** สู่การใช้ถนนร่วมกัน การเข้าถึงของคนเดินและผู้ใช้รถเข็น รถเมล์ ถนนขณะฝนตก และระบบระบายน้ำจากถนนถึงปลายทาง โดยแยกไว้ใน [urban-systems-lab](./urban-systems-lab/) และคงไฟล์โครงการเดิมไว้ทั้งหมด

- ดาวน์โหลด repository แล้วเปิด `urban-systems-lab/index.html` ในเบราว์เซอร์ ใช้งานออฟไลน์ได้ ไม่ต้องติดตั้งหรือเรียกแผนที่จากเครือข่าย
- เลือกพื้นที่ ชั้นข้อมูล และกรณีศึกษาได้ 14 เคส รวมแผนที่แจ้งวัฒนะ–คลองเปรมประชากร–คลองบางตลาด บ่อ ท่อ ปั๊ม น้ำหนุน และผลต่อถนน ป้ายรถเมล์ ทางไร้ขั้น และซอยข้างเคียง
- รุ่นล่าสุด 0.4.0 (6 พฤศจิกายน 2569): ทดลองจบ/หน่วงไฟหลักตามคิวและระดับน้ำปัจจุบัน เทียบกับแผนประสานคงที่ล่าสุด โดยคงช่วงเริ่มข้าม 10 + เคลียร์ 35 วินาที ไฟซอยเดิม ความต้องการเดินทาง และมาตรการน้ำชุดเดียวกัน
- ค่าตั้งต้นคิวสูงสุด **665.84 → 665.84 PCU: ยังไม่ลดเพิ่ม** กรณีฝนรุนแรงอาจเพิ่มเวลารอรถเมล์ จึงแสดงผลเสียและคิวค้างด้วย ไม่สรุปว่าการปรับไฟแบบตอบสนองช่วยได้ทุกสถานการณ์
- ตัวเลขและกฎควบคุมเป็นแบบจำลองเพื่อสำรวจกลไก ไม่ใช่ผลพยากรณ์หรือแบบก่อสร้าง แยกแนวแผนที่ที่มีแหล่งข้อมูลจากท่อ ปั๊ม และจุดทดสอบสมมติ การไม่มีรถลัดซอยเป็นเงื่อนไขของโมเดล ยังต้องตรวจพฤติกรรมและคิวล้นนอกขอบเขตในพื้นที่จริง
